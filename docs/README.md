# SchoolPublisher

## Projektziel

SchoolPublisher erstellt automatisch professionelle Dokumente für den Schulalltag.

Die erste Anwendung ist die Erstellung einer Elternabendübersicht für alle Klassen.

## Datenquellen

- ASV-BW Unterrichtsmatrix
- Lehrerliste
- Klassenlehrer
- Lehrerbilder

## Geplante Module

- Datenimport
- Validierung
- Elternabendblatt
- PDF-Erzeugung
- Layoutsystem
