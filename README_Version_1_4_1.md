# SchoolPublisher 1.4.1

1. `START_Bewertungen.bat` starten.
2. Für jedes Fach Gesamtgewichtung, tatsächliche Erhebungsarten, Anzahl und Gewicht eingeben.
3. Speichern.
4. `START_SchoolPublisher.bat` starten.

Regeln:
- Anzahl leer oder 0: Erhebungsart erscheint nicht.
- Nur tatsächlich vorhandene Erhebungen werden ausgegeben.
- Eine Untergewichtung erscheint nur bei mindestens zwei vorhandenen Arten mit positivem Gewicht.
- Hat ein Fach nur Tests, zeigt die Karte nur Tests und keine Klassenarbeiten.
